📚 Concept #1

Qu'est-ce que le Trading ?

Acheter bas, vendre haut — et automatiser ce processus intelligemment.

📈 Principe fondamental

Le trading consiste à acheter un actif (BTC, action, devise) à un certain prix, puis à le revendre plus cher pour réaliser un profit. Le profit s'appelle le PnL (Profit and Loss).

💱 Une paire de trading

BTC/USDT signifie : combien de dollars (USDT) vaut 1 Bitcoin. On achète du BTC avec des USDT, et on revend du BTC pour récupérer des USDT en plus.

BTC/USDT 67 342.50 ▲ +2.34% ETH/USDT ▼ -0.87%

🕯️ Une bougie (Candlestick)

Chaque bougie représente l'évolution du prix sur une période.
Open · High · Low · Close · Volume

{ open: 67100, high: 67800, low: 66900, close: 67342 }

🔴🟢 Long vs Short

LONG  = Acheter en espérant que le prix monte

SHORT = Parier que le prix va baisser (vendre ce qu'on n'a pas encore)

Notre bot utilise uniquement des positions LONG pour rester simple et sûr.

⚡ Trading Manuel vs Algorithmique

Manuel : Un humain surveille les écrans et clique pour acheter/vendre.

Algorithmique : Un programme analyse les données en continu, sans émotion, 24h/24 — c'est ce que fait notre bot.

📊 Volume

Le volume indique combien de BTC ont été échangés sur la période. Un fort volume confirme un mouvement de prix. Un faible volume peut signifier un faux signal.

📊 Concept #2

Les Indicateurs Techniques

Des formules mathématiques qui transforment les prix bruts en signaux exploitables.

〰️

SMA / EMA

Moyenne mobile. Lisse les prix pour détecter une tendance. Quand la MA rapide croise la MA lente → signal BUY ou SELL.

SMA(10) > SMA(30)
→ TENDANCE HAUSSIÈRE
📉

RSI

Relative Strength Index (0–100). Mesure si le marché est en survente (RSI < 30) ou surachat (RSI > 70).

RSI = 28 → BUY
RSI = 74 → SELL
🌊

MACD

Mesure la dynamique de tendance. Croisement de deux EMA. Quand MACD passe au-dessus de sa ligne signal → BUY.

MACD(12,26,9)
→ Momentum
📦

Bollinger / ATR

Bollinger : Bandes autour du prix. Retour à la moyenne. ATR : Volatilité — utilisé pour calculer notre stop-loss.

SL = prix - 2×ATR
→ Adaptatif
core/indicators.py — Calcul des indicateurs sur les bougies 
class Indicators:
    @staticmethod
    def sma(candles, period) -> float:
        closes = [c["close"] for c in candles[-period:]]
        return sum(closes) / period   # Moyenne simple des N derniers prix de clôture

    @staticmethod
    def atr(candles, period=14) -> float:
        trs = [max(c["high"]-c["low"], abs(c["high"]-prev["close"]), ...) for ...]
        return sum(trs) / period       # Volatilité moyenne → sert à calculer le Stop-Loss
🛡️ Concept #3

Gestion du Risque

La règle d'or : protéger le capital AVANT de chercher des profits.

🎯 Les 3 piliers du RiskManager

ParamètreValeurRôle
Stop-Loss (SL)prix − 2×ATRCoupe la perte automatiquement
Take-Profit (TP)prix + 4×ATRVerrouille le profit (RR 2:1)
Position Size1% capitalTaille calculée pour risquer 1%
Max Drawdown15%Coupe tout si perte globale > 15%

📐 Exemple concret

Capital = 10 000$
Prix BTC = 67 300$
ATR = 150$
───────────────────
Stop-Loss = 67300 - 2×150 = 67 000$
Take-Profit = 67300 + 4×150 = 67 900$
Risque 1% = 100$ / 300$ = 0.333 BTC
core/portfolio.py — RiskManager 
class RiskManager:
  def stop_loss(self, entry, atr, side):
      # Stop 2× la volatilité sous l'entrée
      return entry - 2.0 * atr   # ex: 67300 - 300 = 67000

  def take_profit(self, entry, stop, rr=2.0):
      distance = abs(entry - stop)
      return entry + rr * distance  # Profit = 2× le risque

  def position_size(self, capital, entry, stop):
      risk_$    = capital * 0.01   # 1% de 10000 = 100$
      distance  = abs(entry - stop)
      return risk_$ / distance       # 100/300 = 0.33 BTC

  def check_drawdown(self, equity):
      dd = (self.peak - equity) / self.peak * 100
      return dd < 15.0   # Arrêt si perte totale > 15%
🧠 Concept #4

Les Stratégies de Trading

4 stratégies + 1 vote par ensemble + 1 modèle IA.

〰️

SMA Crossover

Quand la MA rapide (10) dépasse la MA lente (30) → BUY. Signal de tendance.

Marché : Tendance forte
📉

RSI Mean Reversion

Achat en zone de survente (RSI < 30), vente en surachat (RSI > 70).

Marché : Range / Latéral
🌊

MACD Crossover

Croisement de la ligne MACD au-dessus de sa ligne signal → momentum haussier.

Marché : Tendance modérée
📦

Bollinger Bands

Achat quand le prix sort sous la bande basse, vente au-dessus de la bande haute.

Marché : Range / Volatile
core/strategies.py — EnsembleStrategy (vote majoritaire) 
class EnsembleStrategy:
  strategies = [SMACrossover(), RSIStrategy(), MACDStrategy(), BollingerStrategy()]

  def generate(self, data) -> Signal:
      votes = [s.generate(data) for s in self.strategies]
      # Ex: [BUY, BUY, HOLD, BUY] → 3 BUY sur 4 → Signal final = BUY
      buys = votes.count(Signal.BUY)
      return Signal.BUY if buys >= 2 else (Signal.SELL if votes.count(Signal.SELL) >= 2 else Signal.HOLD)

def tick(self) -> dict:
    candle = self.data.fetch_candle()          # 1. Bougie OHLCV
    price  = candle["close"]                    # 2. Prix de clôture
    
    self._check_exits(price)                   # 3. Vérif SL / TP de la position ouverte
    
    signal = self.strategy.generate(self.data) # 4. Stratégie → BUY / SELL / HOLD
    if signal != Signal.HOLD:
        self._execute_signal(signal, price)    # 5. Calcul risque + ouverture position
    
    # 6. Envoi de l'état au dashboard via WebSocket (web_app.py)
    if self.on_candle_cb: self.on_candle_cb(state)
    
    return candle
